# 现存问题

尽管潜力巨大，但区块链技术仍处于早期发展阶段，并面临着若干重大挑战。这些障碍常常阻碍开发者和企业创建那些曾向用户承诺的、广泛应用的去中心化应用。本节将概述 ArcBlock 旨在专门解决的关键问题。

## 性能不佳

性能是当前区块链技术的主要瓶颈。大多数现代消费级应用需要支持数百万日活跃用户，但主流的区块链远远达不到这一要求。

-   **交易速度慢：** 比特币网络的设计处理能力约为每秒七笔交易，而以太坊也只能处理略高的速率。这对于需要大量并发用户才能有效运行的应用来说是远远不够的。
-   **影响用户体验：** 良好的用户体验要求亚秒级的反馈。许多区块链上常见的长时间延迟会令用户感到沮丧，使得去中心化应用相比其传统的中心化应用缺乏竞争力。一个简单的游戏，如 CryptoKitties（加密猫），曾在 2017 年使整个以太坊网络运行缓慢，这表明了这些系统是多么容易变得拥堵。

## 用户体验差

当今的区块链应用通常是为技术专家而非普通消费者构建的。其中涉及的复杂性造成了陡峭的学习曲线，阻碍了其主流普及。

几乎所有的去中心化应用都要求用户运行一个区块链节点，或安装一个专门的“轻节点”钱包，例如浏览器扩展程序。用户还必须学习如何安全地获取和管理加密货币以支付交易费用。为了吸引广大受众，区块链技术必须变得像现代 Web 和移动应用一样无缝和直观，将底层的复杂性对最终用户隐藏起来。

## 成本高昂

使用区块链技术的成本高昂是其普及的一大障碍。这也限制了开发者构建提供免费服务的应用，而免费服务是许多成功的 Web 和移动应用的标配模式。

不应期望用户为他们在应用内采取的每一个微小操作都支付费用。就像互联网一样，区块链技术必须能够支持免费使用的应用，才能实现广泛普及。这将使开发者能够创造有价值的服务并寻找其他盈利策略，而不是将网络费用直接转嫁给用户。

## 平台锁定

与其他计算技术的早期阶段类似，开发者面临着严重的“平台锁定”问题。他们被迫选择一个特定的区块链进行构建，并实现平台特定的代码，这使得日后切换到不同的区块链变得极其困难且成本高昂。

开发者需要自由地评估、使用和切换不同的底层技术，以适应其需求的变化或新出现的更优平台。有些应用甚至可能需要同时在多个区块链上运行，以提供最佳的用户体验。互操作性的缺乏严重限制了灵活性和创新。

## 功能缺失

尽管人们对去中心化应用的未来充满期待，但现实是，当今的区块链技术仍不成熟，缺乏开发者所需的丰富功能。此外，目前也鲜有有效的机制来鼓励社区为核心技术栈做出贡献。

尽管区块链协议很容易被“分叉”（即创建一个新版本），但这些分叉通常只带来微小的改进，同时却分裂了社区并分散了计算资源。大多数区块链系统中的激励结构并非旨在奖励对更广泛技术栈的贡献，从而减缓了创新的步伐。
