# Archive

This section serves as a repository for historical versions of the ArcBlock technical whitepaper. For researchers, developers, and community members interested in the project's evolution, these documents provide a clear record of our foundational ideas and technological progression from the very beginning.

## Token Sale Event Whitepaper

This is the original technical whitepaper published in December 2017 for the ArcBlock Token Sale Event. It outlines the initial vision, architecture, and token economy that set the foundation for the ArcBlock platform. This version is preserved in its original PDF format for historical accuracy and reference.
