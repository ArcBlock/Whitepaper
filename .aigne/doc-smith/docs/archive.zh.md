# 存档

本部分是 ArcBlock 技术白皮书历史版本的存储库。对于有兴趣了解项目演变的研究人员、开发者和社区成员，这些文档清晰地记录了我们从最初开始的基础思想和技术进展。

## 通证销售活动白皮书

这是 2017 年 12 月为 ArcBlock 通证销售活动发布的原始技术白皮书。它概述了为 ArcBlock 平台奠定基础的最初愿景、架构和通证经济。为确保历史准确性和参考价值，此版本以其原始 PDF 格式保存。

## 总结

存档确保所有利益相关者都能访问关键的历史文档，从而提高透明度，并为平台随时间的发展提供背景信息。虽然这些文档作为参考很有价值，但请查阅[最新版本](./overview.md)的白皮书，以获取有关 ArcBlock 技术和路线图的最新、最准确的信息。
