# The Problems

Despite its potential, blockchain technology is still in its early stages and faces several significant challenges. These hurdles often prevent developers and businesses from creating the widespread, decentralized applications that users have been promised. This section outlines the key problems that ArcBlock is specifically designed to address.

## Poor Performance

Performance is a primary bottleneck for current blockchain technologies. Most modern consumer applications need to support millions of active users daily, but popular blockchains fall far short of this requirement.

-   **Low Transaction Speeds:** Bitcoin's network is designed to handle about seven transactions per second, and Ethereum can only manage a slightly higher rate. This is insufficient for applications that require a critical mass of concurrent users to be effective.
-   **User Experience Impact:** A good user experience demands feedback in sub-seconds. The long delays common on many blockchains can frustrate users, making decentralized applications less competitive than their traditional, centralized counterparts. A simple game like CryptoKitties famously slowed the entire Ethereum network in 2017, demonstrating how easily these systems can become congested.

## Poor User Experience

Today's blockchain applications are often built for technical experts, not for the average consumer. The complexity involved creates a steep learning curve that has hindered mainstream adoption.

Nearly all decentralized applications require users to run a blockchain node or install a specialized "light node" wallet, such as a browser extension. Users must also learn how to securely acquire and manage cryptocurrencies to pay for transaction fees. For blockchain technology to attract a broad audience, it must become as seamless and intuitive as modern web and mobile apps, with the underlying complexity hidden from the end-user.

## High Cost

The high cost of using blockchain technology is a major barrier to adoption. It also restricts developers from building applications that offer free services, a standard model for many successful web and mobile apps.

Users should not be expected to pay a fee for every minor action they take within an application. Just like the internet, blockchain technology must be able to support free-to-use applications to achieve widespread use. This would empower developers to create valuable services and find alternative monetization strategies, rather than passing network fees directly to their users.

## Platform Lock-In

Similar to the early days of other computing technologies, developers face a significant "platform lock-in" problem. They are forced to choose a specific blockchain to build on, implementing platform-specific code that makes it extremely difficult and costly to switch to a different blockchain later.

Developers need the freedom to evaluate, use, and switch between different underlying technologies as their needs evolve or as new, better platforms emerge. Some applications may even need to run on multiple blockchains simultaneously to provide the best possible user experience. The lack of interoperability severely limits flexibility and innovation.

## Lack of Features

While there is immense excitement about the future of decentralized applications, the reality is that today's blockchain technology is still immature and lacks the rich features developers need. Furthermore, there are few effective mechanisms to encourage the community to contribute to the core technology stack.

Although blockchain protocols are easy to "fork" (create a new version from), these forks often only introduce minor improvements while splitting the community and fragmenting computing resources. The incentive structures in most blockchain systems are not designed to reward contributions to the broader tech stack, slowing down the pace of innovation.
